Lesson #8 Rules

Present Simple (Negative Form) • 18.11.2026

1 I, We, You, They + don't + verb

Используется с местоимениями I, We, You, They и множественным числом.

I know → I don't know Я знаю → Я не знаю
We understand → We don't understand Мы понимаем → Мы не понимаем
You try → You don't try Ты стараешься → Ты не стараешься
They help me → They don't help me Они помогают мне → Они не помогают

2 He, She, It + doesn't + verb

Используется с местоимениями He, She, It (он, она, оно). Окончание -s у глагола пропадает!

He knows it → He doesn't know it Он знает это → Он не знает это
She wants → She doesn't want Она хочет → Она не хочет
It helps → It doesn't help Это помогает → Это не помогает
It seems → It doesn't seem Кажется → Не кажется странным

Key Lesson Phrases / Ключевые фразы урока:

  • I don't want to discuss it (Я не хочу это обсуждать)
  • I don't want to do it right now (Я не хочу делать это прямо сейчас)
  • I don't want to tell you about this problem (Я не хочу говорить тебе об этой проблеме)
  • I don't want to think about it (Я не хочу думать об этом)
